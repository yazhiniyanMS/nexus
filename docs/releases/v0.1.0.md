NEXUS 0.1.0 is the first public beta: a local-first developer workspace for macOS, Windows and Linux.

## What is in it

- **Projects and Intelligence**: import a folder, see languages, dependencies and findings, a dependency map, symbol and reference search.
- **Search and Git**: search across projects; status, diffs, history, staging.
- **Terminal**: real shells (zsh/bash/fish, PowerShell, Command Prompt) in tabs and splits with saved, searchable output.
- **Tasks**: step lists where every command needs your approval.
- **Model Lab (experimental)**: local runtimes, model library, playground, benchmarks.
- **Agents (experimental)**: plan, implement, test and review in an isolated worktree, with approval at each gate.

## Before you install

- **The installers are not code-signed or notarized.** macOS Gatekeeper and Windows SmartScreen will warn you. Verify your download against `SHA256SUMS.txt`. See the installation guide.
- **Windows and Linux are new.** They are built, tested and install-checked automatically, but have had little hands-on use. Linux is built on Ubuntu 22.04 and other distributions are untested.
- No account, no analytics, nothing uploaded. See the privacy notes.

## Feedback

Use the issue forms (bug, feature, installation, Windows, Linux, performance). In the app, **About & feedback** gives you a diagnostic report to paste in.

## Known issues

- No automatic updates; install new versions over the old one.
- The Git screen cannot commit or push.
- The macOS Intel build has only been launched under Rosetta, not on an Intel Mac.
- Only x64 on Windows and Linux.
