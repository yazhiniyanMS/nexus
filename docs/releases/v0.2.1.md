NEXUS 0.2.1 is a public beta of a free, open-source desktop app for macOS, Windows and Linux. It maps any local codebase without AI, and lets AI agents change code only through your approval.

**Watch the 50-second demo:** `NEXUS-demo-0.2.1.mp4` below (real screen recording of this version). **Website:** https://yazhiniyanms.github.io/nexus/

## What's new since 0.1.0

(0.2.1 is the first public release of the 0.2 line; the `v0.2.0` tag was not released.)

**Understand a codebase without AI**
- **Codebase report**: one HTML file with the module graph, dependency cycles, hotspots, entry points, dependencies, findings and Git facts — and no source code. Overview → Share a report.
- **Architecture map** opens at the folder depth that shows the most dependencies (one to three levels), so nested projects no longer look like one circle.
- **Copy as Mermaid**: paste the map into a README, issue or pull request; GitHub draws it. Names and imports only.

**Change code only through you**
- **Execution levels** for every approved command: Trusted, Restricted (sandboxed: writes only to the project, temporary folders and caches; credential folders and the keychain hidden) and Isolated (Restricted without network). macOS sandbox and bubblewrap on Linux; refused rather than downgraded when unavailable.
- **Time limits** per step and per task; the whole process tree is stopped on timeout, cancel and quit.
- **Credentials withheld** from commands by name and by value; credentials in files an agent edits reach the model as placeholders.
- **Commit from the Git screen**, with merge, rebase and conflict state.

**Getting started and sharing**
- **Guided first run**: add and index a project, connect or start a local Ollama, then next steps. Every step can be skipped.
- **Model Lab → Compare → Copy table**: share benchmark results as Markdown, without prompts or server addresses.
- Redesigned interface; Settings screen.

**Fixed**: two agent runs starting at the same moment could break each other's Git worktree; a possible freeze when a task step waited for approval; a path-traversal in the untracked-file preview; repository configuration that could run programs on `git status`; API keys following redirects; damaged or newer databases ending start-up silently; commands running in the wrong folder; agent workspaces left behind. Full record: [docs/audit/](https://github.com/yazhiniyanMS/nexus/tree/main/docs/audit).

## How this build was checked

- Every platform's installer is built by the release workflow on native GitHub runners, which run the full test suite (206 Rust tests, 25 frontend tests), install the package, launch the installed app and uninstall it.
- The macOS Apple Silicon `.dmg` from this release was also downloaded, checked against `SHA256SUMS.txt`, installed and launched on macOS 27.2 (Apple M5 Pro); the same code was exercised feature by feature in a development build (map, symbols, report, approvals in the macOS sandbox, Git commit, settings).
- Windows and Linux have had **little hands-on use** by a person. Reports are very welcome.

## Known limitations

- Beta, built by one person. Not an editor.
- The code index understands Rust, TypeScript, JavaScript, Python and Go, with line-based rules rather than a full parser.
- Agents and "Ask" need a model. Small local models (around 7B) often fail to produce a valid plan; 14B+ works better.
- Windows offers only the Trusted level (no sandbox backend yet).
- The macOS Intel build is built and launch-checked under Rosetta in CI; it has not been run on an Intel Mac.
- No automatic updates: install new versions over the old one. Your data is kept.
- Full list: [LIMITATIONS.md](https://github.com/yazhiniyanMS/nexus/blob/main/docs/LIMITATIONS.md).

## Privacy

No account, no telemetry, no analytics, no update checks. Project content goes to a model only when you choose one; a model that is not on your computer needs your confirmation for that request. [PRIVACY.md](https://github.com/yazhiniyanMS/nexus/blob/main/docs/PRIVACY.md)
